
# GCS – GRAND CITY STORIES

### The City Never Sleeps

GCS is an ambitious 3D open-world Indian city game project.

## Main Vision
Create a large, immersive fictional Indian city called ANGEL VALLEY.

## Planned Features
- Large open-world Indian city
- Original 3D characters and stories
- Luxury houses and mansions
- Cars, bikes and other vehicles
- Smooth driving mechanics
- Vehicle interiors and animations
- Bodyguards and security systems
- Police and fictional gang systems
- Missions and rewards
- Cinematic sunrise, sunset and weather
- Day and night cycle
- Offline gameplay
- Future online multiplayer

## Development Goals
- Modular code architecture
- Mobile-friendly controls
- Optimized 3D graphics
- Free and open development tools
- Step-by-step testing

## Status
Project setup and planning.
